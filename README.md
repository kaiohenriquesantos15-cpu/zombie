# ZOMBIE RUSH

Jogo de sobrevivência com zumbis — HTML5 Canvas.

## Como jogar

Abra `index.html` no navegador (Chrome/Firefox).

Ou acesse a página do GitHub Pages se estiver habilitada.

### Controles (PC)
- **WASD** — mover
- **Mouse** — mirar
- **Clique** — atirar
- **1-5** — armas
- **Numpad** — habilidades (Dash, Medkit, Granada, Fúria)

### Controles (Celular)
- Joystick + botão de tiro (auto-mira)
- Modo horizontal recomendado

## Features
- Solo e multiplayer local
- Upgrades entre waves
- Skins, bunker de armas, minimapa
- Suporte mobile landscape
